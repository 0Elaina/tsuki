# 数据库通用约定

## 结构变更与归档

业务数据使用独立数据库，结构变更通过 Alembic 显式迁移。迁移执行后，按业务模块归档字段、索引、关系和建表 SQL；操作见 [工程指南](../05-engineering-guide.md#数据库迁移)。

字段说明区分数据库约束与 ORM 填充值，建表 SQL 记录实际数据库结构。整数编码枚举在字段说明和数据库 `COMMENT` 中记录完整映射；索引说明必须给出具体查询或唯一性场景。

## 跨模块约定

表名与字段名使用 snake_case，约束名称复用 [Base.metadata 的命名配置](../../backend/src/tsuki/db/base.py)，由迁移使用同一来源。

时间采用 UTC 并保留时区。必填字段是否具有数据库默认值，以所属表契约为准，直接写库时同样遵守该契约。

模块文档：[认证数据库设计](01-auth.md)。
