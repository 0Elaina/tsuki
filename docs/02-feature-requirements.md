# 功能需求清单

## 产品与访问角色

Tsuki 提供结构化条目与富文本正文相结合的二次元 Wiki，由个人维护。管理端承担数据维护，游客端面向一般用户公开访问。

| 角色 | 访问与操作边界 |
| --- | --- |
| 管理员 | 登录管理端，维护 Wiki 数据并审核 AI 辅助录入结果 |
| 游客 | 无需注册或登录，浏览公开内容、检索条目及使用站内 AI 问答 |

管理端数据维护能力先于游客端开发。本文列出已确认需求，不记录实现进度或完成状态。

## 管理端需求

| 编号 | 需求 | 行为与边界 |
| --- | --- | --- |
| ADM-01 | 管理员登录 | 使用用户名与密码登录，用户名区分大小写；默认有效期 8 小时，期间浏览器重启后保持登录，到期重新登录 |
| ADM-02 | 结构化条目维护 | 维护具有明确字段的 Wiki 条目，支持新增、查询、修改和删除；具体条目类型和字段在对应业务设计中确认 |
| ADM-03 | 条目关联维护 | 维护与查看条目之间的业务关联，使内容能够通过关联关系组织和访问 |
| ADM-04 | 富文本正文维护 | 在可视化编辑器中维护条目正文，保存并恢复正文的内容与格式 |
| ADM-05 | 图片与附件维护 | 为 Wiki 内容上传、引用和管理图片与附件 |
| ADM-06 | AI 辅助录入 | 使用 AI 整理外部资料、提取条目字段，生成供管理员检查的录入结果；资料来源和输入方式在对应功能设计中确认 |
| ADM-07 | AI 录入审核 | 管理员检查并修正 AI 辅助录入结果，确认后才能纳入正式内容；未经审核的结果不直接进入游客可访问的内容与检索索引 |
| ADM-08 | 后台资料处理 | 将耗时的资料处理与检索索引构建作为后台任务执行，不依赖持续保持管理页面请求连接完成处理 |
| ADM-09 | 管理员账号维护 | 通过本机管理命令创建账号与重置密码；同名创建失败，重置时账号不存在则失败，不自动创建或覆盖其他账号 |
| ADM-10 | 退出与登录失效 | 主动退出清除当前浏览器凭据；重置密码使该账号已有登录在下一次认证时失效 |
| ADM-11 | 管理端设备适配 | 桌面支持全部操作；窄屏支持导航及基本操作，复杂表格和编辑区域允许局部滚动 |

## 游客端需求

| 编号 | 需求 | 行为与边界 |
| --- | --- | --- |
| PUB-01 | 匿名访问 | 游客统一匿名访问，不提供用户注册或登录体系 |
| PUB-02 | 条目浏览 | 展示公开条目的结构化信息、正文、关联内容、图片与附件 |
| PUB-03 | 名称查询 | 支持通过名称定位条目，与语义检索分别设计 |
| PUB-04 | 语义检索 | 支持根据自然语言表达检索相关 Wiki 内容，不替代名称精确查询 |
| PUB-05 | AI 问答 | 基于站内正式内容组织回答并提供来源，便于游客核对依据；不将未经审核的辅助录入结果用作正式知识 |
| PUB-06 | 搜索引擎收录 | 公开条目页面支持搜索引擎收录与页面摘要，通过游客端渲染及元数据能力实现 |

## 内容与 AI 边界

- 结构化字段、条目关系与正文共同表达 Wiki 内容，不将全部业务数据压入自由正文。
- AI 辅助录入服务于管理端维护流程，AI 问答服务于游客端内容访问，两者用途分开。
- 检索索引由正式内容生成，能够根据业务事实重新构建；索引不承担正式内容的独立维护职责。
- API 路由、数据表结构、模型供应商及 AI 详细流程在对应设计和实现单元确认，不在本清单中预设。

技术栈与工程原则见 [项目概览](01-project-overview.md)。
